## ✨ Features
- **GPU-Accelerated Animations**: Silky smooth 60fps performance using heavily optimized `transform` and `opacity` properties.
- **Object-Pooled Mouse Effects**: A custom 24-element fixed DOM particle system for the "Fire Cursor" trail, running purely on `requestAnimationFrame` to avoid React re-renders.
- **Cinematic Overlays**: Staggered GSAP menus and Framer Motion modal logic for instantaneous overlay interactions.
- **Premium Design System**: Tailored dark mode typography, glowing amber accents, and transparent glassmorphism elements.

## 🛠️ Tech Stack
- React 19
- Vite 6
- TypeScript
- Tailwind CSS v4
- Framer Motion & GSAP
